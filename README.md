# Manideep's Portfolio ⚡️

This is my personal portfolio website built using **React.js**. It serves as a showcase of my skills, projects, and experience as a developer.

The site is fully responsive, customizable, and hosted directly on GitHub Pages.

## 🚀 Live Demo
You can view my portfolio live here:  
**[https://manideep71234.github.io/deepu-portfolio.github.io/](https://manideep71234.github.io/deepu-portfolio.github.io/)**

## 🛠 Tech Stack
This project uses the following technologies:
* **React.js** (Frontend library)
* **Node.js** (Runtime)
* **CSS/SCSS** (Styling)
* **GitHub Pages** (Hosting)
* **GitHub Actions** (Automated Deployment)
